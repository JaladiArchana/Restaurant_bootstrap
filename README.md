# 🍔 HOTFOOD - Responsive Restaurant Website

## 📖 Description
HOTFOOD is a modern and responsive **Food Ordering Website UI** built using HTML, CSS, and Bootstrap.  
It provides an engaging user experience with multiple sections like menu, offers, delivery, and customer engagement.

The website is designed with a clean layout and smooth navigation to simulate a real-world food delivery platform.

---

## 🚀 Features

- 🏠 Attractive landing page with hero section  
- 🍽️ Explore menu with categorized food items  
- ⭐ "Why Choose Us" section  
- 🚚 Delivery & Payment section  
- 🎁 Customer offers and gift modal 
- 📱 Fully responsive using Bootstrap  
- 🔗 Smooth scrolling navigation  
- 🌐 Social media integration  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- Bootstrap 4  
- JavaScript
